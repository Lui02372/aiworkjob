잔여 Android lint 경고에는 최신 API 비교, API별 속성, JavaScript 활성화, 백업 설정 호환 안내가 있다. 번들 화면만 WebView에 로드하며 외부 HTTPS 페이지는 시스템 브라우저로 연다. 파일·콘텐츠 접근과 혼합 콘텐츠를 막고 JS 네이티브 브리지를 노출하지 않는다. 출시 서명·Play 심사·실제 단말 다양성 검증은 별도다.

현재 지원 수준: 실제 공고 탐색과 개인 작업 준비·제작 시안·납품 사실 기록을 사용할 수 있다. 서버 생성형 AI 실행, 공고별 완성 앱 자동 구현, 실제 채용 확정, 고객 결제와 정산은 연결되지 않았다. 전체 서비스 완성이나 수익 실현으로 판정하지 않는다.

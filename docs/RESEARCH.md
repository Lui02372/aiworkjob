## 오늘 가능한 경로

실제 공고 수집 → 개인 조건 등록 → 초기 조건 비교 → 원문 필수 요건 직접 확인 → 수락 직전 모집 재확인 → 기기 내 작업 페이지 생성 → 원문에서 지원 → 허용 범위 확인 → 업무별 제작·검토 도구 → 미리보기와 최종 납품 링크 → 실제 입금 사실 기록.

Himalayas는 해외 원격 채용 중심이다. 단기 외주, 한국어 업무 또는 AI 도구 사용 허용만 있는 공고라는 보장은 없다. 직접 탐색할 국내 외주 경로를 함께 제공한다. 소득은 채용·계약·업무 수행과 지급 조건이 성립해야 발생한다.

## 조건 일치 점수

| 기준 | 점수 | 확인 방식 |
|---|---:|---|
| 거주국 | 20 | 공고의 locationRestrictions 비교 |
| 근무 시간대 | 10 | 공고의 timezoneRestrictions 비교 |
| 직무 역량 | 30 | 직무 분야와 등록한 실무 역량 비교 |
| 희망 분야 | 15 | 분야 일치 |
| 도구 활용 | 10 | 해당 분야의 준비 도구와 등록 도구 비교. 공고가 그 도구를 요구한다는 뜻은 아님 |
| 경력 | 10 | 시니어 제목·본문의 연수 문구와 프로필 비교 |
| 영어 업무 | 5 | 사용자 확인 |

지역·시간대·직무 역량·경력·영어가 불일치하거나 명시적 AI 금지·전문자격·추가 언어 문구가 감지되면 점수와 별도로 추천에서 제외한다. 자격 판독은 영문 문구에 대한 휴리스틱으로 누락·오탐 가능성이 있다. 전체 필수 기술·학력·취업 허가는 자동 검증하지 않으며 수락 전에 원문 확인을 요구한다.

AI 사용 상태는 미확인/사용자 확인 허용/금지로 별도 저장한다. 허용의 증거와 범위를 입력한 뒤에만 제작 도구·프롬프트를 활성화한다. 제공자가 확인한 인증 배지가 아니다.

## 외부 연결이 필요한 후속 작업

- 국내 API: 운영 주체의 서비스 인증 신청과 키 발급 후 어댑터 구현·실데이터 계약 검증.
- 계정·동기화: 사용자 인증과 소유권 검증을 갖춘 DB, 데이터 삭제·이전 기능.
- 생성형 AI: 운영자가 선택한 서버 모델·키·비용 한도 연결. 현재 지원 초안은 고정 형식이며 제작 화면은 편집기와 기능 템플릿을 사용한다.
- 완성 앱 자동 개발: 공고별 요구사항 확정, 격리된 실행 환경, 생성 코드 검사, 테스트, 승인된 게시를 갖춘 별도 실행기. 현재 업무 스튜디오와 화면 시안은 그 완성 서비스로 표시하지 않는다.
- 수익: 원문 플랫폼에서 실제 계약·지급. 앱은 이를 실행하거나 은행 잔액을 조회하지 않는다.

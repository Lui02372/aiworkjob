# aiworkjob 0.1.1 · 공개 웹과 공유 링크 개선

- 공개 웹: https://lui02372.github.io/aiworkjob/
- Android 제작 링크를 공개 GitHub Pages 주소로 연결해 다른 브라우저에서도 열 수 있도록 수정했습니다.
- GitHub 프로젝트의 하위 경로에서 제작 링크가 잘못된 최상위 주소를 가리키던 문제를 수정했습니다.
- 공개 웹은 공식 API에서 수집한 공고 피드를 사용하며, 수락 전에 현재 모집 상태를 원문에서 직접 확인하도록 요구하고 확인 방식을 기록합니다.
- Android와 Node 웹앱은 수락 직전 공식 API 모집 상태 재확인을 유지합니다.
- 앱 다운로드 버튼은 GitHub 최신 릴리스로 연결합니다.
- GitHub Actions에서 매일 한국 시간 09:15에 공고 갱신·로직/공개 웹 검사 후 웹을 갱신하도록 구성했습니다. 실패한 빌드는 게시하지 않습니다.

다운로드: `aiworkjob-0.1.1-android.apk`, `aiworkjob-0.1.1-webapp.zip`. Android 8.0 이상, 웹 ZIP은 Node.js 24 이상이 필요합니다. APK는 기존 개발 서명을 유지합니다.

기기 내부 저장, 원문에서 직접 지원, AI 사용 허용 확인, 실제 결제·정산 미연결 상태는 이전 버전과 같습니다. 공개 웹은 API 실시간 상태를 확인했다고 표시하지 않습니다.

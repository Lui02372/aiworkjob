# aiworkjob 0.1.2 · 여러 창에서 스튜디오 작업 보존

같은 작업 스튜디오를 여러 창에서 열면 나중에 저장한 창이 앞서 저장된 항목을 지우던 문제를 수정했습니다.

- 다른 창에서 저장한 항목을 최신 목록에 반영합니다.
- 편집 중 다른 창에서 변경하면 입력을 유지하고 충돌을 알려 덮어쓰기를 막습니다. 입력을 복사한 뒤 편집 창을 닫고 최신 항목에 다시 적용할 수 있습니다.
- 저장 직전 최신 값을 확인하고 지원되는 브라우저에서는 Web Locks로 쓰기를 직렬화합니다. 변경 알림을 놓친 창의 저장·삭제도 검사합니다.
- 저장 공간 오류는 성공으로 표시하지 않고 입력을 유지합니다.

검증: 핵심 로직 35개, 정적 웹·스튜디오 13개, 압축 해제 실행 6개, Android API 36 실행 10개, v0.1.1 → v0.1.2 업데이트·기존 데이터 보존 6개 통과. APK 빌드·lint 성공. 기존 개발 서명을 유지했고 versionCode는 3입니다.

[공개 웹](https://lui02372.github.io/aiworkjob/) · [Android APK](https://github.com/Lui02372/aiworkjob/releases/download/v0.1.2/aiworkjob-0.1.2-android.apk) · [웹앱 ZIP](https://github.com/Lui02372/aiworkjob/releases/download/v0.1.2/aiworkjob-0.1.2-webapp.zip). APK는 Android 8.0 이상, 웹 ZIP은 Node.js 24 이상이 필요합니다. `SHA256SUMS.txt`와 `release-manifest.json`을 함께 제공합니다.

공개 웹은 원문 모집 상태를 사용자가 직접 확인합니다. Android와 Node 실행판은 수락 직전 공식 API를 확인합니다. 매칭 수락은 외부 지원·채용 확정이 아닙니다. 저장은 기기·브라우저 내부이며 서버 LLM, 공고별 완성 앱 자동 개발, 클라우드 동기화, 결제·정산은 미연결입니다.

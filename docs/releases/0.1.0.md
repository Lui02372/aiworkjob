# aiworkjob 0.1.0 · Android / 웹앱 테스트 릴리스

AI 활용자를 위한 실제 공고 탐색, 조건별 매칭, 지원·작업 준비·제작 화면을 연결하는 첫 테스트 버전입니다.

## 다운로드

- `aiworkjob-0.1.0-android.apk`: Android 8.0 이상용 개발 서명 APK. 휴대폰에서 내려받아 설치합니다.
- `aiworkjob-0.1.0-webapp.zip`: ZIP을 모두 푼 뒤 Node.js 24 이상 환경에서 `start-aiworkjob.bat` 또는 `node server.mjs`를 실행합니다.
- `SHA256SUMS.txt`, `release-manifest.json`: 다운로드 파일의 해시·버전·실행 요구사항입니다.

## 구현

- Himalayas 공식 공고 조회, 저장, 검색, 분야별 필터.
- 실제 역량·경력·국가·시간대·영어 조건을 비교한 규칙 매칭.
- 수락 직전 모집 상태 재확인과 개인 작업 페이지.
- 원문 지원 링크, AI 사용 조건 확인, 5개 분야 작업 스튜디오, 제작 페이지 미리보기.
- 기기 내부 작업 저장, 납품 링크와 사용자가 확인한 입금 사실 기록.

검증: 핵심 로직 35개, Chrome PC·모바일 27개, Android 에뮬레이터 9개 통과. 실제 지원·채용·입금 성공을 검증한 수치는 아닙니다.

매칭 수락은 외부 지원이나 채용 확정이 아닙니다. 서버 생성형 AI의 완성 앱 자동 개발, 클라우드 동기화, 실제 결제·정산은 미연결입니다. 기존 호스팅 주소는 비공개 접근 범위를 유지하며, 이 릴리스의 웹 ZIP은 자신의 PC에서 실행할 수 있습니다.
